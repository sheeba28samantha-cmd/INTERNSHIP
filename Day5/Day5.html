Week 1 - Day 5

Git Workflow

  1. Create a feature branch
  2. Write and test your code
  3. Stage your changes
  4. Commit your changes
  5. Push the branch to GitHub
  6. Create a Pull Request
  7. Review and merge the Pull Request

Important Git Commands

  • git status - Check repository status
  • git add . - Stage changes
  • git commit - Save changes
  • git push - Upload changes to GitHub
  • git pull - Get changes from GitHub
  • git branch - View branches

Git Merge vs Git Rebase

Git merge combines two branches while preserving their history. Git rebase moves commits onto another branch to create a cleaner and more linear history.

Pull Request Checklist

  • Code is tested
  • Commit message is descriptive
  • Changes are explained
  • Files are organized correctly
  • Pull Request description is complete
