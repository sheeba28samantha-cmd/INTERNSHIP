# Week 2 - Day 2: Responsive Design

## Project Overview

A fully responsive mobile-first landing page created using HTML5 and CSS3.

## Sections

- Hero Section
- Features Section
- Testimonials Section
- Footer

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Design

## Responsive Breakpoints

- 320px - Mobile
- 768px - Tablet
- 1024px - Desktop
- 1440px - Large Desktop

## CSS Grid

CSS Grid is used for the Features section to create a responsive card layout.

## Flexbox

Flexbox is used for:

- Navigation
- Testimonials
- Footer links

## Viewport

The viewport meta tag is included to make the website responsive on mobile devices.

## Testing

The website was tested using Chrome DevTools on different device sizes.

### Device 1
Mobile - 320px

### Device 2
Tablet - 768px

### Device 3
Desktop - 1024px

## Learning Outcome

Learned how to build mobile-first responsive websites using CSS Grid, Flexbox and media queries.
