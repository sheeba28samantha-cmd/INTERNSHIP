Understanding HTML5

Published on September 3, 2026

HTML5 provides the structure of modern websites. Semantic HTML makes web pages easier to understand for browsers, search engines, and assistive technologies.

What is Semantic HTML?

Semantic HTML uses meaningful elements such as header, nav, main, article, section, aside, and footer instead of relying only on generic div elements.

Important HTML5 Elements

  • header - Introductory content for a page or section.
  • nav - Contains navigation links.
  • main - Contains the primary content of the page.
  • article - Represents independent, reusable content.
  • section - Groups related content.
  • aside - Contains related or secondary content.
  • footer - Contains footer information.

Web Accessibility

Accessible websites allow people with different abilities to use and understand web content.

Quick Resources

Use semantic HTML whenever an appropriate semantic element exists instead of using a generic div.
